
# E-Commerce Sales Analysis using SQL

## 📌 Project Overview
This project analyzes e-commerce sales data using SQL to generate business insights.

## 🛠 Tools Used
- SQL Server

## 📊 Key Analysis
- Total Revenue & Average Order Value (AOV)
- Customer Lifetime Value (CLV)
- Monthly Revenue Trends
- Top Customers & Products
- Inactive Customers

## 📈 Key Insights
- Electronics category generated highest revenue
- Top customers contributed major share of sales
- Revenue showed steady growth trend
- Some products had zero sales

## 🧠 SQL Concepts Used
- Joins
- Aggregations
- CTE (Common Table Expressions)
- Window Functions (RANK, LAG)
